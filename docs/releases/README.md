# Release notes

These are the notes that shipped inside each packaged build handed over for
testing, kept verbatim as a record of what was said about each package at the
time it was delivered.

**They are not current documentation.** Each one describes a superseded build
and addresses someone unpacking a zip, so instructions such as "close the
previous instance" or "extract this package" do not apply to a repository
checkout. Figures in them are the figures known when that package was built,
and later notes correct earlier ones.

For current information use:

- [`docs/SURFACE-FREQUENCY.md`](../SURFACE-FREQUENCY.md) - the current path, how
  to build and run it, and its validation results
- [`CHANGELOG.md`](../../CHANGELOG.md) - what changed in each version and why
- [`experiments/`](../../experiments/) - the raw archived evidence
